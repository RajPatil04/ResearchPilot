# ResearchPilot AI — Assets

This directory contains static assets, documentation resources, and test papers for ResearchPilot AI.

## Files
- `sample_paper_researchpilot.pdf`: A sample 3-page scientific research paper created for demo and verification purposes. You can upload this directly into ResearchPilot AI to test:
  1. Paper Summarization
  2. Grounded Q&A with `[PAGE N]` citations
  3. Research Insights & Opportunities
  4. Multimodal Page / Figure Analysis
  5. Agentic Investigation Tools
  6. Dossier Export
